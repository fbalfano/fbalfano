# Apply-the-SEO-Standard Prompt

Copy everything in the block below and paste it into a Claude Code session
opened **inside the repo of one Django site** (run it once per site). It is
self-contained — it does not require this toolkit repo to be checked out.

---

```
Apply our SEO standard to THIS Django site. The goal: serve /sitemap.xml (with
an honest <lastmod> on every URL), /robots.txt, and /llms.txt, all generated by
Django. Work on a new branch, verify locally, then commit and push. Do NOT open
a PR unless I ask.

CONTEXT
- Stack is Django + Tailwind. The current sitemap (if any) has <priority> and
  <changefreq> but no <lastmod>. Search engines (Bing especially) largely ignore
  priority/changefreq but use <lastmod> to decide what to re-crawl. Adding an
  honest <lastmod> is the whole point.

STEP 1 — INSPECT (don't assume; this site has its own pages/models)
- Find the root urls.py and the project settings module.
- List the site's real public pages (named URL patterns / views) and any
  content models that have an updated_at / modified timestamp.
- Check whether django.contrib.sites and django.contrib.sitemaps are installed
  and whether a sitemaps.py / robots.txt / llms.txt already exist.

STEP 2 — SETTINGS
- Ensure INSTALLED_APPS includes "django.contrib.sites" and
  "django.contrib.sitemaps", and SITE_ID = 1.
- Set the Site row's domain to this site's REAL domain (via a data migration or
  management command) so <loc> URLs are correct, not example.com. Ask me for the
  domain if you can't infer it confidently.

STEP 3 — sitemaps.py  (the core change: emit <lastmod>)
- Create/replace sitemaps.py with a Sitemap per content type, protocol="https".
- For DYNAMIC content (models with a timestamp): items() returns the queryset,
  lastmod(obj) returns obj.updated_at. Use the model's get_absolute_url().
- For STATIC marketing pages: a StaticViewSitemap whose items() are the page
  url-names, location() uses reverse(), and lastmod() reads a PAGE_LASTMOD dict
  mapping url-name -> the date that page's content last changed. Seed it with
  today's date for now; I'll adjust real dates.
- Export a `sitemaps = {...}` registry.
- HONEST LASTMOD RULE: never derive lastmod from a template file's mtime (a
  fresh deploy resets it to "now", making every page look changed every deploy —
  Bing distrusts that). Use updated_at for dynamic pages and the maintained
  PAGE_LASTMOD dict for static ones.

STEP 4 — robots.txt and llms.txt (served by Django, rendered with the domain)
- Add a template robots.txt:
      User-agent: *
      Allow: /

      Sitemap: https://{{ site.domain }}/sitemap.xml
  Preserve any existing Disallow rules and any llms.txt reference already there.
- Add a template llms.txt following the llmstxt.org format: an H1 with the site
  name, a one-line ">" summary, and a "## Pages" list of the main URLs. If one
  already exists, keep its content and just ensure it's served at /llms.txt.

STEP 5 — urls.py wiring
- path("sitemap.xml", django.contrib.sitemaps.views.sitemap, {"sitemaps": sitemaps},
       name="django.contrib.sitemaps.views.sitemap")
- path("robots.txt", <view rendering robots.txt with content_type="text/plain"
       and context {"site": get_current_site(request)}>, name="robots_txt")
- path("llms.txt", <same pattern for llms.txt>, name="llms_txt")

STEP 6 — VERIFY locally before committing
- Run the dev server and curl each endpoint:
      curl -s localhost:8000/sitemap.xml
      curl -s localhost:8000/robots.txt
      curl -s localhost:8000/llms.txt
- Confirm EVERY <url> in the sitemap has a <lastmod>, the <loc> URLs use the
  real domain + https, robots.txt has the Sitemap: line, and llms.txt renders.
- If the project has tests/linters, run them.

STEP 7 — SHIP
- Commit on a new branch with a clear message and push it. Then print a short
  summary: which pages/models are in the sitemap, where lastmod comes from for
  each, and the final reminder to (re)submit https://<domain>/sitemap.xml in
  Bing Webmaster Tools and Yandex Webmaster.

Ask me before doing anything ambiguous (e.g. you can't tell which pages are
public, or the real domain). Otherwise proceed end to end.
```

Run it once per site. After it pushes and you deploy, re-submit
