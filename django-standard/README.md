# Django SEO Standard (the "standard build")

Every Django + Tailwind site must expose three files, generated by Django so
they stay correct automatically:

| URL | Source | Purpose |
|---|---|---|
| `/sitemap.xml` | `sitemaps.py` via `contrib.sitemaps` | Tells Bing/Yandex/Google what to crawl — **now with `<lastmod>`** |
| `/robots.txt` | `templates/robots.txt` | Allows crawlers, points to the sitemap (+ llms.txt) |
| `/llms.txt` | `templates/llms.txt` | Guidance for AI/LLM crawlers |

The headline change vs. the old build: **sitemaps now emit `<lastmod>`.** Search
engines largely ignore `<priority>`/`<changefreq>` but use `<lastmod>` to decide
what to re-crawl — so this is the SEO win.

## Files in this standard

- `sitemaps.py` — `Sitemap` classes that implement `lastmod` (the fix).
- `settings_snippet.py` — apps + `SITE_ID` + setting the real domain.
- `urls_snippet.py` — wires `/sitemap.xml`, `/robots.txt`, `/llms.txt`.
- `templates/robots.txt`, `templates/llms.txt` — rendered with the site domain.

## Apply to a site (≈10 minutes)

1. **Settings** — add `django.contrib.sites` and `django.contrib.sitemaps` to
   `INSTALLED_APPS`, set `SITE_ID = 1` (see `settings_snippet.py`).
2. **Set the real domain** — update the `Site` row to the site's domain
   (e.g. `wedraftit.ca`) via data migration or admin, or every `<loc>` will say
   `example.com`.
3. **Copy `sitemaps.py`** into the project. Edit `PAGE_LASTMOD` to list the
   site's static pages (url names) with the date each was last changed. Add a
   model-based `Sitemap` for any dynamic content (uses `updated_at`).
4. **Copy the templates** into a template dir on the `TEMPLATES` `DIRS`/app path
   so `robots.txt` and `llms.txt` resolve. Fill in the `llms.txt` summary.
5. **Wire `urls.py`** from `urls_snippet.py`.
6. **Verify locally:**
   ```bash
   python manage.py runserver
   curl -s localhost:8000/sitemap.xml   # every <url> now has <lastmod>
   curl -s localhost:8000/robots.txt    # Sitemap: line present
   curl -s localhost:8000/llms.txt
   ```
7. **Deploy**, then in Bing Webmaster Tools / Yandex Webmaster (re)submit
   `https://<domain>/sitemap.xml`.

## The lastmod rule (important — don't get flagged)

`<lastmod>` must be **honest**: the date the page's content actually changed.

- **Dynamic pages** → use the model's `updated_at`. Automatic and always honest.
- **Static pages** → maintain `PAGE_LASTMOD` and bump a date only when you edit
  that page.
- **Do NOT** use the template file's mtime — a fresh deploy resets it to "now",
  making every page look changed on every deploy. Bing distrusts sitemaps where
  all `lastmod` values are identical/always today, and it defeats the purpose.

## Rollout across all sites

This repo is the canonical reference. To make **every** site compliant, apply
steps 1–7 in each site's own repo/session (the source isn't in this toolkit
repo). Track progress in `../COMPLIANCE.md`.
