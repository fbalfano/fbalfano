# We Sell Your House — Carousel Brand Assets

Seven-slide Instagram/LinkedIn carousel styled for **wesellyourhouse.ca**, a
seller-focused Canadian real-estate brand ("sell faster, for more, with less
hassle").

## Files

| File | What it is |
| --- | --- |
| `slide-1.png` … `slide-7.png` | Final carousel images, 2160 × 2700 px (1080 × 1350 @2x, 4:5 portrait) |
| `html/slide-1.html` … `slide-7.html` | Editable HTML source for each slide |
| `captions.md` | Ready-to-post caption + hashtags |
| `../` `gen.js` note | Slides are generated by the script referenced below |

## Carousel flow

1. **Cover** — "Thinking of selling your home?" (hook + swipe cue)
2. **Problem** — "Selling shouldn't feel like this" (pain points)
3. **Reason 01** — Sold faster (pricing + marketing)
4. **Reason 02** — More money in your pocket (negotiation + low fees)
5. **Reason 03** — Zero hassle, sell as-is
6. **Proof** — Results stat cards
7. **CTA** — Free home valuation + contact

## Brand system

| Token | Value | Use |
| --- | --- | --- |
| Navy | `#0E2A47` → `#081B30` | Background gradient |
| Gold | `#D4A94F` | Accent, kickers, emphasis, CTA |
| Cream | `#F6F1E7` | Headlines / primary text |
| Muted blue | `#9DB4C9` | Secondary text, page counter |

- **Display type:** serif (Georgia / Charter / Liberation Serif), gold italics for emphasis words.
- **Body / labels:** sans (Helvetica Neue / Liberation Sans), uppercase letter-spaced kickers.
- **Motifs:** thin gold inner frame, line-art house mark, progress dots (current slide highlighted).

## How these were generated

The intended tool for this task was the **Higgsfield** connector, which is **not
connected** in this environment. **Blotato** (the alternative you selected) is
connected but every tool call was rejected with *"MCP tool call requires
approval,"* which a non-interactive session can't clear. So the slides were
instead produced deterministically as HTML rendered to PNG via headless
Chromium (Playwright) — fully self-contained, no external services.

To **regenerate the PNGs** after editing the HTML:

```bash
NODE_PATH=$(npm root -g) node gen.js   # see scratchpad/gen.js in the session
```

## Regenerating in Blotato or Higgsfield

When a generation connector is interactive, use the per-slide prompts in
`captions.md` (section "Generator prompts") to recreate or restyle these slides.
